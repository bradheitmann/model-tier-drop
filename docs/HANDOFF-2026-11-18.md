## 6. Recipes and gotchas

These are the PM's notes plus what the seats reported in the rollup. Their rollup answers are kept in the evidence root (section 7).

- **Seat model.**
  - A fresh Pi session (`/new`) puts a seat on deepseek-flash.
  - To put MTD/QA back on MiMo: `/model`, Enter, Tab to scope "all", type `mimo-v2.6-flash`, Enter.
  - Never press Ctrl+S in the model picker: it changes the shared default.
  - Record each seat's model at dispatch from its session log (`charter seat-evidence --harness pi --session <log>`), never from a receipt.
- **Secrets.**
  - Check a secret by length or shape only.
  - A `!`-prefixed `doppler secrets set` panics, because it has no keyboard input.
  - `pbpaste | doppler secrets set` stored clipboard text. Run `pbpaste | wc -c` first, or use the Doppler dashboard.
- **Gates.**
  - `$HOME/.cargo/bin` first on PATH; `cargo clippy --version | grep -F 'clippy 0.1.98 '`.
  - Root: fmt, clippy, test.
  - Worker crate: fmt, test, wasm32 clippy `-D warnings`.
  - Then `charter check --strict` with the pinned binary, `gitleaks protect --staged --redact` before each commit, and `gitleaks detect --redact` before each push.
  - Use warm target directories (`target/` at the root and `crates/worker/target`). With a cold target, Worker proof 3 takes about 3 minutes.
- **Never run `cargo install worker-build` unpinned on this host.** 0.9.x refuses `worker` 0.8.7. (MTD/QA)
- **QA `charter reopen` in a detached worktree** needs `charter/.freeze/<slice>.json` at the root. Copy it in with `git show <branch>:charter/.freeze/<slice>.json`, then move it and `charter/.freeze/reopen/<slice>.json` out before `git worktree remove`. A plain remove refuses a dirty tree. (MTD/QA)
- **`brief_sha256` in a receipt** is the author brief's hash recorded at dispatch, not the QA brief's. (MTD/QA)
- **`gh run list --repo <url>`** once failed to connect. The same query without `--repo`, from inside the checkout, worked. (MTD/QA)
- **CI lookup:** `gh run list --commit` needs the full sha; a short sha returns nothing.
- **macOS clocks:**
  - `date +%3N` prints a literal `N`; use `gdate -u +%Y-%m-%dT%H:%M:%S.%3NZ`.
  - `stat -f '%Sm' -t '…Z'` prints local time with a `Z` appended. (MTD/DEV)
- **Harness facts outside this repository** (MTD/DEV, for loans to other teams):
  - dsh `0.2.1-rc.2` on this host refuses every shell tool ("no sandbox backend is usable").
  - The free route opencode/longcat-2.5-free returns a 429 with an 11-hour retry, so a QA round on it writes no findings.
